# River 场景实景对照与改造计划

对象：`dist/index.html?scene=river&mood=night`（宜昌夷陵长江大桥北岸江景，9:16，雨夜，10 秒一镜到底）。
参照：`qa/ref-yichang/` 实景照片（bridge-19/20/21/23/26/27、avenue-19/22/23/24/33/45、zhenjiang-08/31 等）与本轮公开资料核实结果。
原则：只改 river 变体的画面内容；`cbd`、`guomao`、`bridge` 逐像素不变。运镜、8/7/5 拍点、下缘遮挡、红色画框、湿地面镜面倒影全部保留。

## 实景核实要点

- 三塔倒 Y 形、单索面混凝土斜拉桥，跨径 120+348+348+120 m；北边塔 106.5 m，中塔 126 m；桥面宽 23 m、双向四车道。
- 塔身白色、带蓝色条纹；夜间塔索由 LED 投光洗亮，桥侧有白色点光源链，塔顶为蓝色光源。早期有七彩循环，现常见白/暖白。
- 北岸驳岸为四级浆砌块石斜坡，每级一条步道（消落带）；江边护栏为灰白花岗岩。树种以法桐、樟树为主。
- 北岸住宅原则不超 18 层 / 55 m，中心区可到 80 m；夜景亮化强调镇江阁、宜化双子座、万达等轮廓与顶部。
- 桥址江面宽约 800 m，有万吨级货轮与待闸驳船；夜间倒影是竖向拉长的长条光带。
- 雨后常见平流雾，桥塔与楼群半没。

## 改造计划

### P1 素材（openai-api-image，均记录 prompt/版本/用量/哈希/目检）

1. `tower-concrete-v001`：白色混凝土塔身，水平模板缝、雨痕、水线污渍；参考 `bridge-20.jpg`。
2. `residential-facade-night-v001`：密集小窗、阳台、空调机位、少量暖窗；参考 `avenue-19.jpg`。
3. `revetment-masonry-v001`：湿浆砌块石斜坡、苔痕、水线；参考 `bridge-23.jpg`。
4. `plane-tree-canopy-v001`：夜间被暖光从下方照亮的法桐树冠，带透明背景思路（暗底）。
5. `skyline-north-night-v002`（可选）：以 `avenue-19.jpg` 为参考重做远景天际线长条。

### P2 桥（river 专属分支）

- 塔身材质：金色自发光 → 冷白；增加蓝色竖条几何（塔身两侧薄面）与塔顶蓝色航空灯。
- 索：提高夜间自发光，锚头白色护套；保持中央索面。
- 桥缘：冷白点光链（实例化小球，仅 river）；红栏杆压暗。
- 桥墩：`tower-concrete` 贴图、水平分节线、水线湿痕、船形防撞套、航行灯。

### P3 北岸近景

- 驳岸改四级石阶 + `revetment-masonry` 贴图，每级加步道灯；保留红色画框栏杆，加花岗岩柱与压顶。
- 步道补花岗岩铺装接缝、积水与倒影；补长椅、系缆柱、救生圈、垃圾桶。
- 增加一段低矮法桐树冠带与绿色地埋洗墙，位置避开塔身与索面。

### P4 北岸楼群与天际线

- 从 `bridge-context` 导出楼栋 footprints（只加返回值，不改 bridge 画面），river 变体给河侧立面叠加夜景立面贴图。
- 2-3 栋楼加顶部灯带/航空障碍灯；补宜化双子座式双塔轮廓（置于画面外或远景，不抢主体）。

### P5 江面与大气

- 水色偏长江的青墨绿；竖向反射拉伸与雨点涟漪增强，镜面底不变。
- 下游加 2-3 艘暗色驳船 + 1 艘低亮度彩灯游船；航行灯点光。
- 江面 6-15 m 低雾带（只在 river，且不遮挡塔顶）；降环境光、提高灯芯曝光。
- 雨丝变细、带风斜；近灯处加雨帘。

### P6 验收

- `npm run check`、`npm run build:local`、`npm run verify:water`。
- 同机位帧：0.20（城市高处）、0.43（人眼）、0.90（收镜）与实景并排，确认“一眼认出”。
- 对照 `bridge` 场景同帧截图，确认三场景无变化；控制台无资源/着色器错误。

## 已知取舍

- 红色画框优先于真实的灰白花岗岩栏杆：保留红栏，改用花岗岩柱础与压顶提升质感。
- 江面宽度维持 700 m（真实约 800 m）：改宽度会移动岸线与机位，破坏既定构图。
- 中塔 126 m 暂不改：远景差值小于 1.5% 画面高，收益低、风险高。
